# Callit

Crypto discovery and social calling platform.

## Current state
Frontend prototype (`index.html`) with mock data. No real wallet, swap or backend yet.

## Deploy
Static site. On Vercel: Import repo → Framework preset "Other" → Deploy. No build step.

## Roadmap
1. Frontend prototype (this)
2. Next.js + TypeScript + Tailwind port
3. Privy wallets, Jupiter swaps, Supabase backend
4. Calls tracking, leaderboard, caller fees
5. Chat, mainnet, $CALLIT
